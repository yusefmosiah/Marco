# Backtest Data

This bundle publishes local backtest outputs that were previously only in
ignored `backtests/runs/`.

Directories:

```text
fred-fx-rate-lab/
experiment-ledger/
```

`fred-fx-rate-lab/` contains the main FX/rate run, including metrics,
predictions, report, config, and feature manifest.

`experiment-ledger/` contains the experiment-runner ledger proof, including
job-level configs, metrics, predictions, statuses, aggregate metrics, gates,
and planning artifacts.
