# Marco Data

This directory contains repo-root data bundles intended to be easy to find from
GitHub.

Committed shareable bundles:

```text
backtests/
ecb-sdmx/
fed-fomc-communications/
fred-fx-rate-lab/
global-macro-panel/
macro-news/
world-bank-indicators/
```

Ignored working caches:

```text
raw/
derived/
```

The ignored `raw/` and `derived/` trees are regenerated by source adapters and
pipelines. The committed bundles are curated copies of the current local data
haul so collaborators can inspect CSV, JSONL, Parquet, raw source snapshots,
news ledgers, manifests, mappings, and backtest outputs without rerunning
fetches.
